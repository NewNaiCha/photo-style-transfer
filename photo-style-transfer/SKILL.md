## Overview

photo-style-transfer 是一个**修图指令生成器**。用户上传照片后，AI 分析照片的摄影参数和风格特征，然后生成一段**可直接复制到豆包等 AI 修图工具的修图提示词**，用户粘贴即可获得专业修图效果。

### 核心能力

1. **图像分析** - 识别照片的摄影参数（镜头、光圈、快门、ISO、光线、构图）
2. **修图指令生成** - 输出可直接复制到豆包的修图提示词
3. **风格推荐** - 根据照片内容推荐最佳修图风格
4. **参数映射** - 将摄影参数转换为 AI 修图工具能理解的指令

### 工作原理

```
用户上传照片
    │
    ▼
AI 分析照片特征
（构图、光线、色调、景深）
    │
    ▼
生成修图指令
（可直接复制到豆包）
    │
    ▼
用户复制 → 粘贴到豆包 → 获得修图效果
```

## Workflow

### Step 1: 读取并分析图片

使用 Read 工具读取用户上传的图片，分析以下维度：

| 分析维度 | 识别内容 |
|----------|----------|
| **构图** | 三分法/中心/框架/引导线/对称 |
| **光线** | 顺光/逆光/侧光/散射光/顶光 |
| **景深** | 浅景深（虚化）/全景深（清晰） |
| **色调** | 暖色/冷色/中性/高饱和/低饱和 |
| **焦段** | 广角/标准/长焦（通过透视判断） |
| **场景** | 人像/风光/街拍/美食/建筑/夜景 |
| **问题** | 过曝/欠曝/偏色/噪点/模糊/构图歪 |

### Step 2: 生成修图指令

根据分析结果，生成一段**结构化的修图指令**，格式如下：

```
【修图指令 - 复制以下内容到豆包】

请对这张照片进行以下调整：

【基础调整】
- 曝光：+0.5EV（画面整体偏亮）
- 对比度：+10（增加层次感）
- 高光：-20（压暗过曝区域）
- 阴影：+15（提亮暗部细节）
- 色温：向暖色偏移（增加温暖感）

【色彩调整】
- 饱和度：+15（增强色彩活力）
- 自然饱和度：+10（自然增色）
- 色调分离：高光加青，阴影加黄

【风格化】
- 模拟85mm f/1.4镜头效果：增强背景虚化，保持主体清晰
- 添加轻微胶片颗粒感
- 整体色调偏暖，模拟黄金时段光线

【细节优化】
- 锐化：+20（增强主体清晰度）
- 降噪：轻度（保持画面纯净）
- 暗角：轻微（增加画面氛围感）

【约束】
- 不要改变人物面部特征和表情
- 不要替换或修改背景内容
- 保持原始构图不变
- 仅做色调和光影优化
```

### Step 3: 输出结果

输出包含三部分：

1. **照片分析报告** - 参数表 + 问题诊断
2. **修图指令** - 可直接复制的完整指令（用代码块包裹，方便一键复制）
3. **修图建议** - 简要说明为什么这样调

## 参数映射表

### 场景 → 模板选择

| 场景 | 使用模板 | 关键参数 |
|------|----------|----------|
| 人像特写 | 模板 A | 暖色温、浅景深 |
| 环境人像 | 模板 A | 自然色温、中等景深 |
| 风光大片 | 模板 B | 高对比、高饱和 |
| 城市建筑 | 模板 B | 冷色调、清晰 |
| 街拍纪实 | 模板 C | 胶片感、颗粒 |
| 美食静物 | 模板 A | 暖色温、浅景深 |
| 夜景城市 | 模板 D | 蓝调、降噪 |
| 蓝调风光 | 模板 B | 冷色调、蓝色时段 |

### 光线 → 色温调整

| 光线类型 | 色温调整 | 说明 |
|----------|----------|------|
| 黄金时段 | 向暖偏移 | 增加温暖金色感 |
| 蓝色时段 | 向冷偏移 | 增加冷蓝氛围 |
| 阴天散射 | 中性偏暖 | 避免画面发灰 |
| 正午阳光 | 中性 | 保持自然色温 |
| 室内暖光 | 向暖偏移 | 增加温馨感 |
| 霓虹灯光 | 保持原色 | 不调整色温 |

### 问题 → 修正指令

| 问题 | 修正指令 |
|------|----------|
| 过曝 | 曝光 -0.5~-1.5EV，高光 -30~-50 |
| 欠曝 | 曝光 +0.5~+1.5EV，阴影 +20~+30 |
| 偏黄 | 色温向冷偏移，降低橙色饱和度 |
| 偏蓝 | 色温向暖偏移，增加暖色饱和度 |
| 灰蒙蒙 | 对比度 +15~+25，饱和度 +10~+20 |
| 噪点多 | 降噪强力，轻微柔化 |
| 模糊 | 锐化 +30~+50，清晰度 +20 |
| 构图歪 | 裁剪旋转（需用户手动操作） |

## Error Handling - 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| 图片无法读取 | 提示用户检查图片格式（支持 JPG/PNG/WEBP） |
| 图片内容不明确 | 主动询问："这是人像/风光/其他类型的照片？" |
| 多人合照 | 提示："多人合照建议使用环境人像模板" |
| 图片质量太差 | 建议先降噪再调色，给出具体降噪参数 |
| 用户描述模糊 | 主动询问具体需求："想要什么风格？日系/电影感/胶片？" |
