# photo-style-transfer 使用示例

## 示例 1：古镇风光照片修图指令

### 用户输入
用户上传一张古镇雪山照片，说"帮我修一下这张照片"

### AI 分析流程

```markdown
我看到了一张古镇雪山风景照片，让我分析并生成修图指令：

【构图分析】
- 框架式构图：左侧树干形成前景框架
- 三分法：雪山置于画面上方1/3处
- 纵深感：前景→中景（古镇）→远景（雪山）

【光线分析】
- 光线方向：侧光/侧逆光
- 色温：暖色调（上午10点左右）
- 光影对比：强对比，明暗分明

【景深分析】
- 景深：中等偏深（f/5.6-f/8）
- 虚化程度：轻微虚化，前中后景都较清晰
- 焦距估算：约35-50mm（中焦段）

【问题诊断】
- 画面整体对比度偏低，灰蒙蒙
- 阴影区域细节不足
- 色彩饱和度偏低

→ 匹配模板 B（风光大片）
```

### 输出修图指令

```text
请对这张照片进行以下调整：

【基础调整】
- 曝光：+0.3EV（画面整体偏暗）
- 对比度：+15（增强画面层次，去除灰蒙蒙感）
- 高光：-30（压亮天空，恢复云层细节）
- 阴影：+25（提亮古镇暗部细节）
- 色温：向暖偏移（增强上午阳光的温暖感）

【色彩调整】
- 饱和度：+20（增强古镇建筑和雪山的色彩）
- 自然饱和度：+15（自然增色，避免过度）
- 色调分离：高光偏青（天空），阴影偏黄（古镇建筑）

【风格化】
- 模拟风光摄影滤镜效果
- 增强画面通透感，去除雾霾感
- 添加轻微暗角增加画面氛围
- 增强前景树干的纹理质感

【细节优化】
- 锐化：+30（增强古镇建筑纹理和雪山细节）
- 降噪：中度（保持画面纯净）
- 清晰度：+20（增强整体质感）

【约束】
- 保持原始构图不变
- 不添加或删除画面中的任何元素
- 不改变地平线位置和雪山形态
- 仅做色调和光影优化
```

## 示例 2：人像照片精修指令

### 用户输入
用户上传一张人像照片，说"分析照片参数，帮我生成修图指令"

### AI 分析流程

```markdown
【构图分析】
- 中心构图，人物居中
- 背景简洁，主体突出

【光线分析】
- 自然光，偏柔
- 色温中性偏暖

【景深分析】
- 浅景深，背景虚化明显
- 焦距估算：约85mm（人像焦段）

【问题诊断】
- 面部阴影略重
- 背景虚化不够自然
- 整体色调偏平淡

→ 匹配模板 A（人像精修）
```

### 输出修图指令

```text
请对这张人像照片进行以下调整：

【基础调整】
- 曝光：+0.5EV（提亮整体画面）
- 对比度：+10
- 高光：-25（压亮部，保护肤色不过曝）
- 阴影：+20（提亮面部阴影）
- 色温：向暖偏移（增加温暖感）

【肤色优化】
- 降低橙色饱和度：-10（避免肤色过橙）
- 提亮肤色明度：+5
- 降低红色通道：-5（去红润）
- 轻度磨皮（保留皮肤纹理）

【风格化】
- 模拟85mm f/1.4镜头效果：增强背景虚化，保持主体清晰
- 背景添加柔和的圆形光斑（bokeh）
- 主体边缘添加轻微的轮廓光
- 整体色调偏暖，模拟黄金时段光线

【细节优化】
- 锐化：+20（增强眼部和发丝清晰度）
- 降噪：轻度（保持画面纯净）
- 暗角：轻微（增加画面氛围感）

【约束】
- 严格保持人物面部特征和表情不变
- 不改变面部形状和五官位置
- 不替换或修改背景内容
- 仅做肤色优化和光影调整
```

## 示例 3：街拍照片调色指令

### 用户输入
用户上传一张街拍照片，说"这张照片怎么调好看？想要胶片感"

### AI 分析流程

```markdown
【构图分析】
- 引导线构图，街道延伸形成透视
- 人物处于画面三分之一处

【光线分析】
- 漫射光为主
- 色温中性

【场景判断】
- 街拍/纪实类照片
- 用户明确要求胶片感

→ 匹配模板 C（街拍/纪实）+ 预设 4（胶片复古）
```

### 输出修图指令

```text
请对这张街拍照片进行以下调整：

【基础调整】
- 曝光：+0.2EV
- 对比度：+10
- 高光：-15
- 阴影：+10

【色彩调整 - 胶片感】
- 饱和度：-10（胶片低饱和特征）
- 自然饱和度：-5
- 色调分离：高光偏绿，阴影偏橙
- 轻微偏色（整体偏黄绿）

【风格化 - 胶片复古】
- 添加中等颗粒感（模拟ISO 400胶片）
- 添加轻微漏光效果（画面边缘）
- 暗角中度
- 降低整体锐度（胶片柔和感）

【细节优化】
- 锐化：+5（轻微锐化即可）
- 清晰度：+5
- 色彩纯度：+5

【约束】
- 保持原始构图和画面内容
- 不改变人物动作和表情
- 保持纪实摄影的真实感
- 胶片颗粒感要自然，不能过度
```

【问题诊断】

- 暗部噪点明显
- 色彩不够丰富

→ 匹配模板 D（夜景/低光）

请对这张夜景照片进行以下调整：

【细节优化】

【约束】
- 保持灯光颜色和位置不变
- 不添加或删除光源

```markdown

分析照片特征后，将电影感预设参数与照片实际情况结合，
生成定制化的修图指令。
```

请对这张照片进行以下调整：

【细节优化】

## 常见问题处理

### Q1: 用户说"帮我修一下"但没指定风格

**处理方式**：
1. 先分析照片类型（人像/风光/街拍/夜景）
2. 自动匹配最佳模板
3. 同时推荐 2-3 个风格预设供用户选择

### Q2: 用户上传的照片质量太差

**处理方式**：
1. 先诊断问题（过曝/欠曝/噪点/模糊/偏色）
2. 生成修复指令（优先修复基础问题）
3. 再叠加风格化调整

### Q3: 用户想要特定风格但照片类型不匹配

**处理方式**：
1. 告知最佳匹配模板
2. 说明为什么推荐该模板
3. 如果用户坚持，按用户要求生成指令

### Q4: 多人合照怎么处理？

**处理方式**：
1. 使用环境人像模板（模板 A 变体）
2. 约束中强调"保持所有人物面部特征不变"
3. 建议降低磨皮强度，避免多人效果不统一
