## 一、定焦镜头推荐

### 1.1 24mm f/1.4

| 属性 | 说明 |
|------|------|
| 视角 | 84°（全画幅） |
| 最近对焦距离 | 约0.25m |
| 适合题材 | 风光、建筑、室内、人文、环境人像 |
| 虚化能力 | ★★★★☆ |
| 便携性 | ★★★☆☆ |

**推荐理由**：风光摄影的利器，广角中拥有大光圈，可在弱光下拍摄星空而不需要极慢的快门速度。

**拍摄技巧**：
- 风光：f/8-f/11 获得全景深
- 星空：f/1.4 + ISO3200 + 15-20s
- 人像：注意变形，人物放边缘以外

## 五、镜头参数解读

### 5.1 MTF 曲线

MTF（Modulation Transfer Function）衡量镜头对比度和分辨率表现：

| 曲线类型 | 含义 |
|----------|------|
| 10线对/mm | 分辨率（细节表现） |
| 30线对/mm | 反差（对比度） |
| 实线 | 对比度 |
| 虚线 | 分辨率 |

**判断标准**：
- 曲线越高越好
- 边缘与中心差距越小越好
- 实线高于虚线

## 六、镜头保养建议

1. **防潮**：使用防潮箱存放，尤其是南方潮湿地区
2. **防尘**：户外更换镜头时背对风向
3. **清洁**：
   - 镜头纸/气吹清理灰尘
   - 镜头液+麂皮清洁指纹
   - UV镜保护前镜片
4. **存放**：盖好前后盖，置于干燥处
